Genuine OJ

Genuine-OJ 是一个由 @yang-zhongtian @yxzlwz 等开发的开源 OJ 项目。

  • 仓库地址
  • API 接口文档（注：更新可能滞后）

我们致力于打造一个界面美观、功能实现较为齐全、方便部署和二次开发的“小而美”的 OJ 平台。

技术栈

  • 前端：Vue3 + NaiveUI
  • 后端：Python3 + Django + Django-Rest-Framework + Celery + Redis + RabbitMQ
  • 评测端：Python3
  • 评测沙箱：C++
